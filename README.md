# astrbot_plugin_group_welcome 入群欢迎

AstrBot 入群欢迎插件。检测到新人入群后自动发送欢迎语。

## 功能

- 入群欢迎：监听 aiocqhttp（OneBot v11）的 `group_increase` 通知事件，自动发送欢迎消息。
- 全局默认欢迎语：在 WebUI 插件配置中设置。
- 每群单独设置欢迎语：在 WebUI 插件配置的「每群单独欢迎语」卡片中点击「添加条目」逐群配置（群号 + 欢迎语 + 图片），也可通过指令为当前群设置，两者互通。
- 欢迎图片：全局默认图片和每群单独图片（URL 或本地路径），群配置优先于全局。
- 群黑白名单：黑名单模式（名单内的群不欢迎）或白名单模式（仅名单内的群欢迎），在 WebUI 插件配置中设置。

## 占位符

欢迎语中支持以下占位符：

- `{at}`：AT 新入群的成员（仅 aiocqhttp 平台支持 At 消息段）
- `{name}`：新成员昵称
- `{group}`：群号

## 指令（仅管理员）

| 指令 | 说明 |
| --- | --- |
| `/欢迎设置 <欢迎语>` | 为当前群设置欢迎语 |
| `/欢迎图片 <URL或路径>` | 为当前群设置欢迎图片，参数填「无/清除/删除」则清除 |
| `/欢迎查看` | 查看当前群的欢迎语 |
| `/欢迎删除` | 删除当前群欢迎语，恢复使用全局默认 |

## 配置项（WebUI 插件配置）

- `enabled`：是否启用入群欢迎
- `global_welcome`：全局默认欢迎语（群未单独设置时使用）
- `global_image`：全局默认欢迎图片（可选，URL 或本地路径）
- `group_welcomes`：每群单独欢迎语（template_list 卡片，每条含群号、欢迎语、图片）
- `list_mode`：`blacklist`（黑名单模式，默认）/ `whitelist`（白名单模式）
- `blacklist`：群黑名单，填群号
- `whitelist`：群白名单，填群号

## 平台支持

入群通知检测基于 aiocqhttp（OneBot v11）适配器的 `raw_message`，其他平台适配器暂不支持。
